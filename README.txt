SmartSort 1-Click PC File Organizer v1.0 — CreatorTools Hub
============================================================
Automatically sorts messy folders (like Downloads or Desktop) into clean subfolders:
Images, Videos, Audio, Documents, Archives, Installers, Code, and Other.

How to use (1 Click):
1. Copy or move SmartSort.bat into any messy folder (for example, your Downloads folder).
2. Double-click SmartSort.bat.
3. Every file is sorted instantly into clean folders without overwriting duplicates!
